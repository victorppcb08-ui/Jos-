# 📚 Estudo_Português — Câmara dos Deputados (Cebraspe)

Série de guias de estudo de **Língua Portuguesa** para a prova de **Analista Legislativo da Câmara dos Deputados**, banca **Cebraspe** (formato **Certo/Errado** — *uma errada anula uma certa*).

Cada guia segue a mesma lógica: **mecânica da banca → conceitos → tabelas comparativas → armadilhas/pegadinhas → bizus → simulado C/E comentado (na cadeira do examinador) → plano de estudo**.

## 🧭 Como usar esta pasta

1. **Aprenda** pelo guia do tema (módulos 00 a 09).
2. **Treine** com o simulado C/E de cada guia, cobrindo o gabarito.
3. **Diagnostique** o erro pela "manobra da banca" indicada no comentário.
4. **Revise** com a lista de armadilhas e os bizus na véspera.

Convenção de nomes: `NomeDoTema_Cebraspe.html`. Numeração e status ficam nesta tabela — assim a pasta cresce sem bagunçar.
